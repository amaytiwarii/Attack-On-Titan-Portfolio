# ⚔️ Attack on Titan Interactive Experience

An immersive Attack on Titan-themed web experience built with React, Vite, and GSAP. This project recreates the atmosphere of the anime through cinematic scroll-driven animations, video storytelling, and interactive Titan size comparisons.

## 🚀 Live Features

### 🎬 Cinematic Hero Section
- Scroll-controlled video playback
- GSAP-powered animations
- Storytelling inspired by Attack on Titan
- Smooth chapter transitions
- Dynamic text reveals

### 👹 Titan Size Comparison
- Interactive height comparison system
- Compare Humans with various Titans
- Animated scroll-based presentation
- Detailed information for each Titan

### 🧭 Custom Navigation
- Attack on Titan themed navbar
- Animated hover effects
- Responsive design
- Smooth user experience

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/amaytiwarii/Attack-On-Titan-Portfolio.git
```

Move into the project directory:

```bash
cd attack-on-titan-experience
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
